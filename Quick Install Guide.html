Arth – Quick Install Guide

Arth (local) v0.3.0 ko apne Chrome me lagane ke aasaan steps. Poora kaam 2–3 minute ka hai.
Screenshot me laal dabbe aur number batate hain ki kahan click karna hai.

1Folder apne computer me rakho

Jo arth-main folder (ya zip) mila hai, use kisi pakki jagah rakho, jaise Documents. Agar zip file hai to us par right-click karke Extract All karo.
Dhyan rahe: install ke baad is folder ko delete ya move mat karna, warna extension band ho jayega.

2Chrome me extensions page kholo

Chrome kholo. Upar address bar me ye likho aur Enter dabao: chrome://extensions

3Developer mode ON karo

Page ke upar right corner me Developer mode ka switch hai. Us par click karke use ON (blue) karo.

4Load unpacked dabao

Developer mode ON hote hi upar left me naye button aayenge. Load unpacked par click karo.

5prototype folder chuno

Ek folder chunne wali window khulegi. Usme arth-main folder kholo. Andar prototype naam ke folder par ek baar click karo (4), phir neeche Select Folder dabao (5).
Sirf prototype folder chunna hai, poora arth-main nahi.

6Check karo ki Arth (local) aa gaya

Ab list me Arth (local) 0.3.0 naam ka card dikhega. Uska switch ON (blue) hona chahiye. Bas, install ho gaya.

7ChatGPT me login kar lo

Naye tab me chatgpt.com kholo aur apne account se login kar lo. Ye sirf ek baar karna hai. Arth apne jawab ChatGPT se hi lata hai, isliye login zaroori hai. Free account bhi chalega.

8Use karo

Koi bhi website kholo aur mouse se koi word ya line select karo. Neeche do button aayenge (7):
  • Arth – select kiye hue text ka matlab samjhata hai.
  • Ask – us text ke baare me apna sawaal likh sakte ho.

9Jawab yahin dikhega

Kuch second me jawab ek chhote box me aa jayega. Usi box me neeche aur sawaal bhi pooch sakte ho. Box band karne ke liye Esc dabao ya page par kahin aur click karo.

Kaam ki baatein

  • Pehli baar use karne par Chrome me ek ChatGPT ka tab apne aap khulega. Use band mat karna, Arth usi se jawab lata hai.
  • Pehla jawab thoda time leta hai (lagbhag 10 second). Uske baad ke jawab jaldi aate hain (lagbhag 5 second).
  • Jo page install se pehle se khule the, unhe ek baar refresh (F5) kar lo, tabhi un par button aayenge.
  • Chrome kabhi-kabhi start hote waqt "Disable developer mode extensions" ka popup dikhata hai. Use cancel / close kar do, Disable mat dabana.
  • Agar button nahi aa rahe: chrome://extensions me dekho ki Arth (local) ka switch ON hai, aur page refresh karo.
  • Agar jawab ki jagah login ka message aaye: ChatGPT wale tab me login karke dobara try karo.
  • Ye build sirf apne personal use ke liye hai. Ise aage publish ya share mat karna.
